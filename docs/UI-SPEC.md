# UI-спецификация TermDeck

Эталон: `docs/prototype/termdeck-prototype.html` (откройте в браузере).
Прототип задаёт внешний вид и структуру, но не код.

Минимальный размер окна: 900 px. Ширины сайдбара и SFTP-панели меняются
перетаскиванием и сохраняются. Ctrl+B скрывает сайдбар, Ctrl+Shift+B скрывает SFTP.

## Типографика

IBM Plex Sans 13 px для интерфейса. JetBrains Mono 13 px / 1.5 для терминала;
11 px для путей, прав доступа и размеров. Шрифты бандлятся через @fontsource.

## Компоненты → папки

| Элемент прототипа | Компонент | Папка |
|---|---|---|
| Дерево сессий, поиск, кнопки внизу | `SessionsSidebar`, `SessionTree`, `SessionRow` | `features/sessions` |
| Полоса вкладок с точкой статуса и × | `TabBar`, `Tab` | `features/tabs` |
| Панель действий под вкладками | `ActionBar` | `features/tabs` |
| Breadcrumbs, таблица файлов | `SftpPanel`, `PathBar`, `FileTable` | `features/sftp` |
| Блок «Передачи» | `TransferList`, `TransferItem` | `features/sftp` |
| Область терминала | `TerminalView` | `features/terminal` |
| Нижняя строка | `StatusBar` | `app` |

Данные компоненты получают через хуки (`useSessions`, `useSftpListing`, `useTransfers`),
чтобы на этапе 0.5 подставлялись моки, а позже реальный IPC.

## Состояния

- **Вкладка:** подключение, подключено, разрыв, ошибка (цвет точки + баннер «Переподключиться»).
- **Строка файла:** обычная, hover, выбрана, при перетаскивании (подсветка зоны drop).
- **SFTP-панель:** загрузка (skeleton), «Папка пуста», нет прав, нет соединения.
- **Передача:** в очереди, идёт, пауза, готово, ошибка (кнопка «Повторить»).
- **Плашка «SFTP следует за терминалом (OSC 7)»:** активна, выключена, недоступна.
- **Редактор (вкладка):** иконка файла, точка вместо × при несохранённых изменениях.

## Тексты

Русский, sentence case, активный залог, без восклицательных знаков. Кнопка называет
действие («Новая сессия», «Повторить»). Ошибка объясняет, что случилось и что делать.
Пустое состояние предлагает действие. Все строки в `src/renderer/i18n/ru.ts`.

## Доступность

Видимый фокус на интерактивных элементах; вкладки и дерево сессий управляются с
клавиатуры (стрелки, Enter); роли `tablist`, `tree`, `table`; учитывать
`prefers-reduced-motion`.

## Что в прототипе упрощено

Состояние глобальное (в приложении на вкладку); колонки таблицы файлов ограничены
шириной 310 px (в приложении добавляются «Дата» и «Владелец», скрываются по ширине);
эмодзи вместо иконок; нет drag & drop, контекстных меню, множественного выбора;
данные захардкожены (в приложении список виртуализируется); есть мобильный адаптив
(в приложении не нужен).
