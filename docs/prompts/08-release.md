# Этап 8: упаковка и качество

Прочитай `CLAUDE.md`.

1. electron-builder: NSIS/portable (Windows), dmg (macOS), AppImage/deb (Linux);
   `asarUnpack` для нативных модулей; иконки.
2. Автообновление через electron-updater (настраиваемое и выключаемое).
3. Playwright e2e с моком SSH-сервера (ssh2 Server в тестовом окружении): подключение,
   выполнение команды, листинг SFTP, загрузка файла.
4. Аудит безопасности по чек-листу: флаги окна, CSP, отсутствие утечки секретов в логи
   и crash-репорты, валидация всех IPC-входов, отсутствие remote-контента в renderer.
5. Профилирование: 20 вкладок, проверить память и CPU; починить утечки.
6. CI (GitHub Actions): lint, typecheck, test, сборка артефактов на трёх ОС.
