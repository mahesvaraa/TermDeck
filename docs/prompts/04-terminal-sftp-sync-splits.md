# Этап 4: синхронизация терминала с SFTP и сплиты

Прочитай `CLAUDE.md` и `docs/UI-SPEC.md`. Плашка «SFTP следует за терминалом» в
ActionBar имеет три состояния (активна / выключена / недоступна). Кнопки
«Разделить →/↓» из прототипа подключи к дереву панелей.

ЗАДАЧА: связать терминал и SFTP-панель, добавить сплиты.

СДЕЛАТЬ:
1. Shell integration: при открытии SSH-shell, если включено в настройках, отправить
   в канал невидимую инициализацию, которая для bash (`PROMPT_COMMAND`), zsh (`precmd`)
   и fish (событие `fish_prompt`) печатает OSC 7: `ESC ] 7 ; file://host/path BEL`.
   Инициализация не должна засорять экран и историю (ведущий пробел, очистка строки);
   опиши ограничения.
2. Renderer: `term.parser.registerOscHandler(7, ...)` → обновляет текущий путь
   терминала в сторе → SFTP-панель (при включённой опции «Следовать за терминалом»)
   делает cd. Кнопка «Открыть терминал здесь»: отправляет `cd '<path>'` с корректным
   экранированием кавычек.
3. Сплиты: внутри вкладки дерево панелей (горизонтальные/вертикальные деления) на
   react-resizable-panels; действия: split right/down, close pane, фокус стрелками
   (Alt+Arrow). Каждая панель — независимый терминал (локальный или тот же SSH-хост).
4. Состояние раскладки сериализуется (для будущего восстановления сессии).

КРИТЕРИИ ПРИЁМКИ:
- `cd /var/log` в bash/zsh → SFTP-панель показывает /var/log.
- Пути с пробелами и кавычками обрабатываются корректно.
- Сплит из 4 терминалов работает, resize каждого корректен.
- При выключенной опции интеграции в терминал ничего не отправляется.
