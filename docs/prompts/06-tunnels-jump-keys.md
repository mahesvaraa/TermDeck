# Этап 6: туннели, jump host, ключи

Прочитай `CLAUDE.md` и `docs/UI-SPEC.md`. Кнопка «Туннели» в ActionBar уже есть:
подключи к ней панель из этого этапа в стиле остального интерфейса.

ЗАДАЧА: SSH-туннели, jump host, менеджер ключей.

СДЕЛАТЬ:
1. Tunnel service на ssh2: Local (-L: forwardOut + локальный net.Server),
   Remote (-R: forwardIn), Dynamic (-D: SOCKS5-сервер поверх forwardOut).
   `TunnelConfig` хранится в SessionConfig; запуск/остановка вручную или автоматически
   при подключении. Статус и счётчики трафика.
2. UI: панель «Туннели» для сессии: таблица, добавление/редактирование, тумблер,
   понятные ошибки (порт занят).
3. Jump host (ProxyJump): `SessionConfig.jumpHostId`; подключение через цепочку
   (несколько хопов) с использованием forwardOut к следующему хосту как `sock`.
4. Менеджер ключей: список ключей из `~/.ssh` и добавленных вручную, генерация (ed25519),
   импорт, просмотр публичной части и копирование, проверка шифрования passphrase,
   кнопка «Скопировать на сервер» (аналог ssh-copy-id).

КРИТЕРИИ ПРИЁМКИ: проброс порта БД через туннель работает; подключение через
bastion-хост работает; при закрытии сессии все туннели закрываются.
