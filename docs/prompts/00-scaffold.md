# Этап 0: каркас

Прочитай `CLAUDE.md` и `docs/PLAN.md`.

ЗАДАЧА: создать каркас проекта.

СДЕЛАТЬ:
1. Инициализировать проект на electron-vite (шаблон react-ts), включить TypeScript strict.
2. Настроить ESLint, Prettier, Tailwind, алиасы путей (@main, @renderer, @shared).
3. Создать структуру папок из `docs/PLAN.md`, раздел «Архитектура».
4. Настроить BrowserWindow с безопасными флагами и CSP для renderer
   (без remote-контента, шрифты и скрипты только локальные).
5. Реализовать типизированный IPC-слой:
   - `shared/ipc-contract.ts`: описание каналов (invoke-каналы и event-каналы)
   - в preload экспонировать `window.api` с методами, сгенерированными из контракта
   - в main — хелпер `registerHandler(channel, zodSchema, handler)`
   - демо-канал `app:getVersion` для проверки цепочки
6. Минимальный UI-заглушка: боковая панель, область вкладок, строка статуса.
   Тёмная тема по умолчанию. (Полноценный интерфейс делается на этапе 0.5.)
7. Скрипты: dev, build, typecheck, lint, test. Один тест Vitest для примера.

КРИТЕРИИ ПРИЁМКИ:
- `npm run dev` открывает окно, в статус-баре видна версия приложения, полученная через IPC.
- typecheck, lint и build проходят без ошибок.
- В renderer нет ни одного импорта из Node/Electron.

НЕ ДЕЛАТЬ: терминал, SSH, SFTP, полноценную вёрстку.
