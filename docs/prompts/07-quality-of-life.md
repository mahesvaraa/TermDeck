# Этап 7: удобства

Прочитай `CLAUDE.md` и `docs/UI-SPEC.md`. Реализуй функции по одной, с отдельным
коммитом на каждую. Для каждой добавь настройки в окно «Настройки» и покрой логику
юнит-тестами.

1. Палитра команд (Ctrl+Shift+P): поиск по сессиям, действиям, настройкам.
2. Сниппеты: библиотека команд с папками и переменными `{{var}}`; вставка в активный
   терминал; опция «выполнить сразу».
3. Multi-exec: ввод одновременно в выбранные терминалы (кнопка уже есть в ActionBar).
4. Поиск по буферу терминала (Ctrl+Shift+F) на addon-search.
5. Темы терминала и UI (импорт схем iTerm2/Windows Terminal JSON), шрифт, размер,
   ligatures, курсор, scrollback.
6. Настраиваемые горячие клавиши.
7. Восстановление сессии: при старте предложить восстановить вкладки и раскладку.
8. Логирование вывода терминала в файл (опционально, с вырезанием ANSI-кодов).
