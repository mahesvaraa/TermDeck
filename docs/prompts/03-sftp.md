# Этап 3: SFTP-панель

Прочитай `CLAUDE.md` и `docs/UI-SPEC.md`. Панель, breadcrumbs, таблица и блок «Передачи»
уже вёрстаны: замени моки реальными данными. Добавь колонки «Дата» и «Владелец»
(в прототипе их нет из-за ширины 310 px): колонки скрываются по ширине панели,
показ настраивается правым кликом на заголовке. Позицию панели (слева/снизу)
сделай настройкой.

ЗАДАЧА: SFTP-панель для SSH-вкладок.

СДЕЛАТЬ:
1. `main/services/sftp/SftpService`: поверх существующего SSH-соединения лениво открывает
   sftp-канал. Методы: list(path), stat, mkdir, rename, delete (рекурсивно), chmod,
   realpath, readFile/writeFile для небольших файлов.
2. `TransferQueue`: upload/download файлов и папок рекурсивно через потоки
   (createReadStream/createWriteStream), параллелизм настраиваемый (по умолчанию 3),
   прогресс (байты, скорость, ETA), пауза/отмена/повтор, конфликт имён (перезаписать /
   пропустить / переименовать — диалог с «применить ко всем»). События прогресса
   троттлятся до ~10 раз/с.
3. UI панели (слева или снизу от терминала, ресайзится, скрывается):
   - строка пути (breadcrumbs, редактируемая по клику), кнопки «вверх», «обновить»
   - список файлов: имя, размер, дата, права, владелец; сортировка;
     виртуализация (`@tanstack/react-virtual`); иконки по типу
   - выбор нескольких (Ctrl/Shift), контекстное меню: скачать, загрузить сюда,
     новая папка, переименовать, удалить, права, копировать путь
   - drag & drop: из ОС в панель = upload; из панели в проводник = download
   - нижний блок «Передачи» с очередью и прогрессом
4. Панель привязана к SSH-вкладке: переключение вкладки меняет содержимое панели;
   путь, выбор и очередь хранятся на вкладку. Для локальных вкладок панель показывает
   локальную ФС или скрыта (решить и описать).
5. Ошибки: нет прав, файл удалён, разрыв во время передачи (задача → failed с кнопкой
   «Повторить»).

КРИТЕРИИ ПРИЁМКИ:
- Каталог с 10 000 файлов открывается без заметных лагов.
- Загрузка файла 2 ГБ не увеличивает потребление памяти (потоки).
- Рекурсивная загрузка/скачивание папки работает, отмена прерывает передачу.
- Закрытие SSH-вкладки отменяет её передачи и освобождает sftp-канал.
