# Этап 0.5: UI-каркас по прототипу

Прочитай `CLAUDE.md`, `docs/UI-SPEC.md` и `docs/prototype/termdeck-prototype.html`.

ЗАДАЧА: собрать интерфейс по прототипу. Без реальной логики: все данные моковые,
SSH/SFTP/pty не подключаем.

ПЕРЕД НАЧАЛОМ:
Кратко опиши, из каких блоков состоит раскладка и какие токены/размеры ты извлёк
из прототипа. Жди моего «ок».

СДЕЛАТЬ:
1. `src/renderer/styles/tokens.css`: все токены цвета, радиусов, шрифтов из прототипа
   (тёмная тема + светлая под `[data-theme="light"]`); подключить в Tailwind theme,
   чтобы использовать классы вида `bg-panel`, `text-mut`, `border-line`.
2. Локальные шрифты через @fontsource; переключатель темы (system/dark/light) в сторе
   настроек, значение сохраняется.
3. Компоненты из таблицы «Компоненты → папки» (`docs/UI-SPEC.md`) со всеми состояниями.
   Данные берутся из mock-слоя `src/renderer/mocks/` (сессии, файлы, передачи)
   через хуки `useSessions`, `useSftpListing`, `useTransfers`: потом моки заменятся
   реальным IPC без правки компонентов.
4. Раскладка на CSS grid/flex + react-resizable-panels: ширина сайдбара и SFTP-панели
   меняется перетаскиванием и сохраняется; панели скрываются (Ctrl+B — сайдбар,
   Ctrl+Shift+B — SFTP). Минимальная ширина окна 900 px.
5. Зона терминала пока рендерит заглушку с моковым текстом (xterm подключим на этапе 1).
6. Доступность: видимый фокус, навигация по вкладкам и дереву с клавиатуры,
   aria-роли tablist/tree/table, prefers-reduced-motion.
7. Storybook НЕ добавлять. Вместо него страница `/dev/ui-gallery` (только в dev-режиме)
   со всеми компонентами и их состояниями.
8. Состояние UI (путь SFTP, выбор, передачи) держи на вкладку, а не глобально.

КРИТЕРИИ ПРИЁМКИ:
- Скриншот окна визуально совпадает с прототипом; отличия перечислены списком.
- Все состояния из `docs/UI-SPEC.md` видны на ui-gallery.
- В компонентах нет захардкоженных цветов (hex/rgb); проверить grep'ом.
- Темы переключаются без перезапуска, область терминала остаётся тёмной.
- typecheck, lint, build проходят; Node/Electron в renderer не импортируются.

НЕ ДЕЛАТЬ: реальный SSH/SFTP, xterm.js, drag & drop вкладок.
