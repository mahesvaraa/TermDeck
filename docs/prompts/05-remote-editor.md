# Этап 5: редактор удалённых файлов

Прочитай `CLAUDE.md` и `docs/UI-SPEC.md`. Вкладка-редактор использует те же
`Tab`/`TabBar`, с иконкой файла и индикатором несохранённых изменений (точка вместо ×).

ЗАДАЧА: редактирование удалённых файлов.

СДЕЛАТЬ:
1. Двойной клик по файлу в SFTP-панели (< 5 МБ, текстовый по эвристике: нет NUL-байтов
   в первых 8 КБ) открывает вкладку-редактор на Monaco: подсветка по расширению,
   определение кодировки (UTF-8 по умолчанию, ручной выбор) и окончаний строк.
2. Ctrl+S сохраняет через `SftpService.writeFile` атомарно: запись во временный файл
   рядом и rename; права и владельца оригинала сохранять там, где возможно.
3. Проверка конфликтов: перед сохранением сравнить mtime/size с теми, что были при
   открытии; при расхождении — диалог (перезаписать / сохранить копию / отмена).
4. Индикатор несохранённых изменений на вкладке; подтверждение при закрытии.
5. Опция «Открыть во внешнем редакторе»: скачать во временную папку, следить за
   изменениями (chokidar), при сохранении предлагать залить обратно; временные
   файлы удалять при закрытии.

КРИТЕРИИ ПРИЁМКИ: изменённый файл на сервере обновляется, права сохранены, при
параллельном изменении файла на сервере пользователь получает предупреждение.
