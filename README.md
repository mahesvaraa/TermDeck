# TermDeck — набор для старта

Клон MobaXterm: терминал, вкладки, SFTP-панель, менеджер сессий. Этот набор —
план, спецификация интерфейса и пошаговые промпты для ИИ-агента (Claude Code, Cursor и т.п.).

## Что внутри

```
CLAUDE.md                       мастер-контекст (агент читает всегда)
docs/PLAN.md                    анализ MobaXterm, стек, архитектура, этапы, подводные камни
docs/UI-SPEC.md                 раскладка, токены, компоненты, состояния
docs/PROGRESS.md                трекер этапов (обновляет агент)
docs/prototype/
  termdeck-prototype.html       кликабельный прототип (откройте в браузере)
docs/prompts/                   промпты по этапам 0 → 8
```

## Как начать

1. Создайте пустой репозиторий, распакуйте архив в корень.
2. Откройте папку в Claude Code / Cursor. `CLAUDE.md` подхватится автоматически.
   (Для Cursor/Codex скопируйте его как `AGENTS.md` или в `.cursor/rules`.)
3. Отправьте агенту содержимое `docs/prompts/00-scaffold.md`.
4. Проверьте критерии приёмки руками, сделайте `git commit`, скажите «принято».
5. Переходите к следующему файлу по порядку.

## Порядок этапов

| Файл | Результат |
|---|---|
| 00-scaffold | окно, безопасный IPC, сборка |
| 00b-ui-shell | интерфейс по прототипу на моках |
| 01-terminal-tabs | локальные терминалы во вкладках |
| 02-ssh-sessions | SSH и сохранённые сессии |
| 03-sftp | файловая панель и передачи |
| 04-terminal-sftp-sync-splits | SFTP следует за `cd`, сплиты |
| 05-remote-editor | правка удалённых файлов |
| 06-tunnels-jump-keys | туннели, bastion, ключи |
| 07-quality-of-life | палитра команд, сниппеты, темы и т.д. |
| 08-release | установщики, автообновление, e2e, CI |

Этапы 0–3 дают рабочий MVP.

## Советы

- Один этап за раз, коммит после каждого принятого.
- Если агент «поехал», откатитесь и переформулируйте, а не чините поверх.
- Если путается в API `ssh2` или xterm.js, попросите прочитать типы в `node_modules`.
- Для known_hosts, секретов и IPC-валидации попросите отдельный проход
  «code review с точки зрения безопасности».
